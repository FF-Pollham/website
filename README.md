# ff-pollham.at

Website of the Freiwillige Feuerwehr Pollham (volunteer fire department of Pollham, Austria).

A static site built with plain HTML, CSS, and JavaScript: no frameworks, no tracking.
Hosted on GitHub Pages and deployed automatically via GitHub Actions.

## Contents

- **Home page** (`index.html`): single-page site with all sections
- **Events**: pulled automatically from the FF Pollham Calendar
- **News**: posts are kept in `data/news.json`
- **Legal notice** and **privacy policy**: `impressum.html`, `datenschutz.html`
